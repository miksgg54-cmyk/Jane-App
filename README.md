# تطبيق جين | Jane App 🎙️💬

**تطبيق جين** هو منصة للدردشة والتواصل والتفاعل الصوتي، تتيح للمستخدمين إنشاء غرف صوتية جماعية، التراسل الفوري، وتبادل الوسائط بسهولة وسرعة.

---

## 🌟 مميزات التطبيق

* **غرف صوتية مباشرة (Voice Rooms):** إنشاء وإنضمام للغرف الصوتية بجودة عالية والتفاعل مع الحضور.
* **دردشة كتابية فورية (Chat):** محادثات شخصية (خاصة) ومحادثات جماعية داخل الغرف.
* **نظام الرتب والصلاحيات:** إدارة المشرفين، المتحدثين، والمستمعين داخل الغرف الصوتية.
* **إرسال الهدايا والتفاعلات:** دعم التفاعل المباشر بين المستخدمين داخل الغرف.
* **واجهة مستخدم عصرية:** تصميم بسيط وسهل الاستخدام يدعم اللغة العربية بشكل كامل.

---

## 🛠️ التقنيات المستخدمة

* **الواجهة الأمامية (Frontend):** Flutter / React Native
* **الخلفية (Backend):** Node.js / Python
* **الاتصال الصوتي (Voice Engine):** WebRTC / Agora SDK
* **قاعدة البيانات (Database):** MongoDB / Firebase
